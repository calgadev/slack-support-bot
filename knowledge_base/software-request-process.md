# Software Request Process

Acme keeps a catalog of approved software. Installing unapproved software on company devices is not allowed.

## Installing approved software

Many applications are pre-approved and can be installed without a request:

- **Windows**: open **Acme Software Center** and click *Install*.
- **macOS**: open **Acme Self Service** and click *Install*.

Examples of pre-approved software: web browsers, the PDF reader, the approved video conferencing client, Python, Visual Studio Code and 7-Zip.

## Requesting software that is not in the catalog

1. Open the Acme Service Portal and choose **Software > New Software Request**.
2. Give the software name, version, vendor website and business justification.
3. Your manager approves the request.
4. The Security team reviews new software. This takes up to **5 business days**.
5. If the software needs a paid license, the cost is charged to your department's cost center.

## Licenses

Paid licenses (for example design or statistics tools) are assigned to a person, not a device. When you no longer need a license, release it through the portal under **Software > Release License** so it can be reused.

## Rejected requests

Requests are usually rejected when the software has known security issues, an approved alternative exists, or the vendor cannot meet Acme's data protection requirements. The rejection note explains the reason and suggests alternatives when available.
